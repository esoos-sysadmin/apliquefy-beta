Para começar

  1. Instale TTF ou OTF. No seletor de fontes, a Regular aparece como Apliquefy Display R2; a Bold permanece em Apliquefy Display.
  2. Use SVG nos layouts e PNG quando a ferramenta exigir imagem raster.
  3. Abra o catálogo para consultar cores, estados, medidas e exemplos.
  4. Preserve a estrutura de pastas para manter os exemplos funcionando.
